# Kami reading fonts

These two local font files are used only by the Library and Wiki reading views.

- `TsangerJinKai02-W04.ttf`: regular article text
- `TsangerJinKai02-W05.ttf`: headings and emphasis

Source: the locally installed `kami` skill, originally distributed by
https://github.com/tw93/Kami.

The UI, navigation, chat history, inputs, and buttons do not use this font.
Before redistributing a public binary release, verify the upstream font terms
and retain any attribution required by the font author.
