# Study Loop — 学习闭环引导

帮助用户走完一轮完整的学习流程。这个 skill 负责"下一步该做什么"，不负责长篇解释资料内容。

## 边界

- 用户只是问"XX 是什么 / 这段资料怎么理解 / 在哪里出现过"：使用 `course-learning`。
- 用户说"考前复习 / 错题重做 / 薄弱点训练 / 来不及了"：使用 `exam-prep`。
- 用户说"同步资料 / 整理笔记 / 导出到 Obsidian / wiki"：优先使用 `obsidian-workspace`。
- 用户要开始、继续、查看、推进一个学习流程：使用本 skill。

## 阶段判断

问用户或从上下文推断当前在哪个阶段：

1. **不确定有没有资料** → 先调用 `knowledge_status`。没有知识库时，再请用户提供 Obsidian vault 或课程资料路径用于同步。
2. **有资料但没有计划** → 调用 `learning_path`，根据目标生成学习计划。
3. **有计划但不知道今天做什么** → 调用 `learning_plan_progress`，`action="today"`。
4. **有到期复习** → 调用 `learning_review`，把复习项和今日计划合并成一份短清单。
5. **需要练习** → 调用 `quiz_start`。如果题库不足，再调用 `question_generate` 生成针对主题的题目。
6. **做题中** → 等用户作答后调用 `quiz_submit`，一次只处理一题。
7. **想看效果** → 调用 `learning_progress`，展示掌握度和最需要推进的 3 个概念。
8. **想导出** → 有学习计划时调用 `obsidian_export_plan`；有做题记录时调用 `obsidian_export_quiz_summary`。

## 学习计划流程

当用户说"帮我制定学习计划"或"我要学 XX"：

1. 先用 `rag_search` 搜索相关资料，确认知识库里有内容
2. 用 `learning_path` 生成个性化学习计划
3. 告诉用户计划内容，问是否开始第一天任务
4. 用户确认后，调用 `learning_plan_progress` 查看今日任务，再开始练习

## 每日复习流程

当用户说"今天学什么"或"复习一下"：

1. 调用 `learning_plan_progress`，`action="today"` 获取计划任务
2. 调用 `learning_review` 获取到期复习清单
3. 如果两者都有，先安排到期复习，再安排计划任务
4. 如果都没有，建议查看学习进度或创建新学习计划

## 进度查看

当用户说"学习进度"或"我学得怎么样"：

1. 调用 `learning_progress` 展示掌握度概览
2. 指出最薄弱的 3 个知识点
3. 给出一个下一步动作：复习、继续计划、或生成练习题

## 导出笔记

当用户说"导出笔记"或"导出到 Obsidian"：

1. 确认 vault 路径
2. 有计划时调用 `obsidian_export_plan`
3. 有做题记录时调用 `obsidian_export_quiz_summary`
4. 告诉用户文件写到了哪里；不要伪造未产生的导出文件

## 语气

- 不要一次性把所有工具调用都列出来
- 每次只引导下一步，等用户确认再继续
- 用中文交流，工具名和路径用英文
- 输出短而明确，重点是让用户继续行动
