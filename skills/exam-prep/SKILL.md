# Exam Prep — 考前复习模式

针对用户的薄弱知识点进行集中训练。优先用已有学习进度和题库；题库不足时再生成新题。

## 边界

- 普通"今天学什么 / 开始学习 / 制定长期计划"：使用 `study-loop`。
- 单个概念解释或查资料：使用 `course-learning`。
- 明确考试、冲刺、薄弱点、错题、来不及：使用本 skill。

## 流程

1. **诊断薄弱点**
   - 调用 `learning_progress` 查看掌握度概览
   - 调用 `learning_review` 查看今日到期复习
   - 向用户展示最薄弱的 3-5 个知识点，不要一次铺开太多

2. **制定复习策略**
   - 优先级：needs_review > learning > mastered
   - 如果用户说"来不及了"，只处理 needs_review
   - 每轮只处理一个概念，每个概念 3-5 道题

3. **集中训练**
   - 先调用 `quiz_start`，尽量使用已有题库
   - 如果题库不足或没有相关题，再调用 `question_generate` 针对该概念补题
   - 引导用户逐题作答，然后调用 `quiz_submit`
   - 每题做完立即反馈对错和知识点解释

4. **复习后检查**
   - 每个概念做完后调用 `learning_progress` 看掌握度变化
   - 仍然薄弱的概念建议第二天再复习

5. **错题重做**
   - 当前没有独立的 `quiz_wrong` 工具时，不要调用不存在的工具
   - 用 `learning_progress` 找低分概念，再围绕这些概念 `quiz_start` 或 `question_generate`
   - 明确告诉用户：现在按薄弱概念重练，不伪造错题本

## 语气

- 紧迫感但不焦虑："考前最重要的是巩固薄弱点，不要贪多"
- 每次只专注一个概念，不要一次铺开太多
- 进展要及时反馈："这个概念你已经掌握了" / "还需要再练几道"
- 如果用户说"来不及了"，建议只复习 needs_review 的概念
