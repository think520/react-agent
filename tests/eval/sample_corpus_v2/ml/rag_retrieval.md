# RAG 检索与证据门禁架构

## 混合检索与倒数排名融合

本地个人知识库结合 SQLite FTS5 稀疏全文检索与稠密语义向量召回，采用倒数排名融合 RRF 算法合并两路候选片段得分。稀疏分支精准匹配专有名词、符号和错误码，稠密语义分支补足同义转述与概念口语化提问的召回短板。

## 确定性引用与证据门禁

每一条检索命中的文本片段都会依据其来源标识计算确定性六位短哈希标签。回答生成后，运行时引用门禁先剥离代码块噪声，再核验正文里所有引用标签是否均真实存在于本轮已采纳证据集合内，严禁模型凭空编造未检索来源编号。

## 语义降级可见性

当向量存储被其它进程占用锁死或用户未配置向量模型时，检索层会主动回落至纯全文模式，并在检索状态中返回不可用原因及替代行为标识，绝不静默假装向量检索正常运行。前端卡片据此向学习者显式提示当前检索状态。
