# Transformer 注意力架构解析

## 缩放点积与多头自注意力

Transformer 完全依赖注意力机制建模序列长距离相关性，摒弃了循环网络的串行时间步依赖。计算查询与键的点积后需要除以维度平方根作为缩放因子，防止高维内积绝对值过大导致 Softmax 梯度陷入饱和区。多头机制把特征切分为多个独立投影子空间并行捕捉不同语义搭配。

## 位置编码与掩码矩阵

自注意力本身对输入单词排列顺序具有置换不变性，因此必须在词向量输入层显式注入正弦余弦或可学习的位置编码以区分 token 先后次序。在自回归解码器中还必须叠加下三角因果掩码矩阵，屏蔽当前时间步之后尚未生成的未来 token，保证训练并行化与推理因果一致性。

## KV Cache 推理加速原理

自回归文本生成每一步只需预测下一个词元，若每次重算整段前缀的键与值投影矩阵将造成大量冗余计算。缓存历史解码步骤算出的 Key 和 Value 张量（即 KV Cache），后续单步只计算当前新 token 投影并拼接读取历史键值表，从而大幅降低生成延迟并换取时间。
