## 2. 修复清单

### 2.1 练习页空白（用户报告）

- 根因：`.practice-create` 自带 `border-top` + `border-bottom` + `padding: 28px 0`，在 tab 栏和出题区之间形成「一条横线 + 28px 空白」。
- 修法：改成卡片表面（`.surface-2` + `--border-subtle` + `--radius-lg` + 16/18 内边距），`border-top/bottom` 一并去掉；`.practice-start` 去掉 900px 限宽，与页头对齐。
- 附带：`.practice-mode` 出题方式从大圆角 chip 改为与设置页一致的**分段控件**，并修掉「被拉成整宽」的 bug（`width: fit-content`）。

### 2.2 复习页宽屏散乱（用户报告）

- 根因：`.review-container { max-width: 980px }` 嵌套在 `.page-container { max-width: 1120px; margin: 0 auto }` 里，**二次居中**；宽屏下左右各空出一大块，列表像浮在中间。
- 修法：`.review-container { max-width: none }`，与页头、分隔线同宽。

### 2.3 中文按钮换行（笔记 / 题库）

- 根因：标题栏动作按钮没有 `white-space: nowrap`，中文在两行折断（「管理全/部」「导出/Markdown」）。
- 修法：全局给按钮、分段控件、标题栏动作加 `white-space: nowrap`。

### 2.4 题库练习集空态

- 根因：`<details class="bank-sets">` 折叠态仍带边框和内边距，视觉上像一个坏掉的输入框。
- 修法：折叠态改成「轻分隔行」（仅 `border-top: --border-subtle`），展开态才显示完整容器。
